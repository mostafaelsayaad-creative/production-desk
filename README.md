# Agency X Production Desk

A working demo of a video production traffic system: admins assign jobs, each team member accepts and delivers stage by stage with links, reviews are logged, and every person gets a performance score.

**Live demo:** https://mostafaelsayaad-creative.github.io/production-desk/

- Sample people, clients and jobs are fictional.
- Everything runs in the browser. Changes stay until you reload; nothing is saved to a server.
- Use **View as** (top right) to switch between the admin view and any team member's view.

Built by Mostafa Elsayaad as part of *The Production Engine* proposal.
